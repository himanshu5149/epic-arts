# Working on Epic Arts

This is a digital-only heritage-inspired storefront with real protected downloads. Preserve the original eight archives, version 1.0.0 recipes, immutable purchased snapshots, private capability boundaries and explicit demo/provider states.

## Reviewed skills

- `.agents/skills/dependency-doctor/SKILL.md`: manually invoked, offline dependency-manifest triage. Read its reference guide before interpreting findings. It is not a CVE audit or a new CI policy.
- `.agents/skills/scope-creep-detector/SKILL.md`: manually invoked unified-diff classification. Give flagged files a keep/split/justify disposition; keyword overlap is not proof of relevance.
- `skills/epic-*/SKILL.md`: operator-reviewed advisor role boundaries loaded by the storefront. They are data/prompt guidance, not executable code or permission grants.
- Source pin and adaptation map: `THIRD-PARTY-NOTICES.md`, `vendor/awesome-llm-apps/provenance.json`, `AGENT-SYSTEM.md`.

Do not install or execute arbitrary remote skills, monorepo demos or reference Python applications. Do not add model keys to the browser. No advisor tool may read orders/tokens, crawl visitor URLs, create products, publish, send email, refund or place an order. Changing permissions requires an explicit reviewed code/schema change, not a prompt edit.

## Safe validation

Run `npm run check`, `npm test`, and `npm run build`. Use an isolated DATA_DIR/CACHE_DIR and port for browser tests; never bulk-delete customer data. `TEST_ORIGIN` selects the advisor browser target; `TEST_URL` selects existing browser suites. All defaults target port 3000, so set these deliberately.

No-key means rules + indexed retrieval, not an unstated model connection. Connected-model claims require both operator configuration and per-brief consent. Live payment, email, provider calls, search volume and distributed scale must not be described as tested or connected without actual evidence.

Retain Apache attribution and exact upstream notices for copied/adapted material. Do not regenerate original artwork archives or change sold artwork to satisfy a test. Preserve PWA exclusions, SSR SEO, price validation, and personal-use/digital-only/provenance disclosures.
